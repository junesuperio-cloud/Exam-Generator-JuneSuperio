🌐 Domain Configuration

Student exam links are built using the GITHUB_PAGES_URL Script Property in your Apps Script.

Script PropertyGITHUB_PAGES_URL
Current value should behttps://junesuperio-cloud.github.io/Exam-Generator-JuneSuperio

To update: open your Apps Script editor → Project Settings → Script Properties → set GITHUB_PAGES_URL to https://junesuperio-cloud.github.io/Exam-Generator-JuneSuperio. Exam and score pages include noindex tags so they are not indexed by search engines.
